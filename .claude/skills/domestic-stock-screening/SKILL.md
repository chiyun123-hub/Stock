# 국내 주식 스크리닝

## 절차

1. **기준 지수 확인**: `korean-stock-search` 스킬로 코스피/코스닥 지수 및 주요 종목의 최근 며칠간 시세(종가, 거래량)를 조회한다.

2. **1차 후보 추출 (시세 기반)**: 다음 패턴을 보이는 종목을 1차 후보로 뽑는다.
   - 상승 신호: 최근 2~3거래일 연속 상승 + 거래량 증가, 또는 급등 후 눌림 없는 지속 상승
   - 하락 신호: 최근 2~3거래일 연속 하락 + 거래량 증가, 또는 주요 지지선 이탈
   - 1차 후보는 넉넉히(각 방향 20~30개) 뽑아 다음 단계에서 걸러낸다.

3. **뉴스 교차검증**: `naver-news-search` 스킬로 1차 후보 종목명을 검색해 최근 뉴스(실적, 계약, 공시, 규제, 소송 등)를 확인한다. 시세 방향과 뉴스 톤이 일치하는 종목만 남긴다.
   - 예: 시세가 상승 중인데 뉴스가 부정적(실적 부진, 소송 등)이면 후보에서 제외하거나 "상충 신호"로 별도 표기.

4. **증권사 리포트 확인**: `daishin-report-search` 스킬로 남은 후보의 최근 리포트를 조회해, 목표주가 상향/하향, 투자의견 변경이 있는지 확인한다. 있으면 근거를 보강하고, 없으면 시세+뉴스 2개 신호만으로도 채택 가능하다(리포트는 필수가 아니라 보강 신호).

5. **최종 선별**: 신호 강도(일치하는 신호 개수, 뉴스/리포트의 최신성)로 정렬해 상승 최대 10개, 하락 최대 10개를 확정한다. 시가총액이 지나치게 작거나 거래대금이 희박해 정보 신뢰도가 낮은 종목은 제외한다.

## 출력 형식

```markdown
# 국내 주식 분석 - {날짜} {시간}

## 상승 예상 후보 (최대 10개)
1. **{종목명}({종목코드})** — 근거: {신호1}; {신호2}
2. ...

## 하락 예상 후보 (최대 10개)
1. **{종목명}({종목코드})** — 근거: {신호1}; {신호2}
2. ...

## 상충 신호 (참고)
- {종목명}: 시세는 {방향}이나 뉴스/리포트는 {반대방향} — 판단 보류

## 참고
- 데이터 기준 시각: {timestamp}
- 조회한 데이터: 시세({N}종목), 뉴스({N}건), 리포트({N}건)
- 누락된 데이터: {있으면 명시}
```

## 주의

- 이는 확정된 예측이 아닌 공개 정보 기반 참고용 스크리닝이다. 결과 문구에 "추천", "매수", "매도" 같은 단정적 표현을 쓰지 않는다.
- 단일 신호(시세만, 뉴스만)로는 채택하지 않는다.
