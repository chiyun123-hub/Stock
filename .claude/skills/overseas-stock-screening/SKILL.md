# 해외 주식 스크리닝

## 절차

1. **거시 맥락 확인**: `bok-ecos-stats` 스킬로 원/달러 환율과 기준금리 최근 추이를 조회한다. 환율이 급등(원화 약세)하면 해외주식 보유 시 원화 환산 수익에 유리한 방향이므로, 이 맥락을 리포트 참고 정보로 남긴다.

2. **시세 조회**: WebSearch/WebFetch로 공개 시세 정보(예: 주요 금융 뉴스 사이트, 거래소/기업 공식 발표)를 조회해 S&P500·나스닥 주요 구성 종목 중 최근 며칠간 뚜렷한 상승/하락 추세를 보이는 종목을 찾는다.
   - 상승 신호: 연속 상승 + 거래량 증가, 실적 서프라이즈, 긍정적 가이던스
   - 하락 신호: 연속 하락 + 거래량 증가, 실적 쇼크, 부정적 가이던스, 규제/소송 이슈

3. **뉴스 교차검증**: WebSearch로 후보 종목의 최근 뉴스(실적 발표, 신제품, 규제, 소송, 경영진 변화)를 확인해 시세 방향과 일치하는지 검증한다. 출처가 불명확한 커뮤니티 글이 아닌, 신뢰 가능한 뉴스/기업 발표 위주로 확인한다.

4. **최종 선별**: 서로 다른 신호 최소 2개가 일치하는 종목만 채택한다. 상승 최대 10개, 하락 최대 10개로 정렬한다.

## 출력 형식

```markdown
# 해외 주식 분석 - {날짜} {시간}

## 거시 맥락
- 원/달러 환율: {값} ({추세})
- 기준금리: {값}

## 상승 예상 후보 (최대 10개)
1. **{종목명}({티커})** — 근거: {신호1}; {신호2}
2. ...

## 하락 예상 후보 (최대 10개)
1. **{종목명}({티커})** — 근거: {신호1}; {신호2}
2. ...

## 참고
- 데이터 기준 시각: {timestamp}
- 국내 대비 정보 실시간성이 낮을 수 있음(시차 고려)
- 누락된 데이터: {있으면 명시}
```

## 주의

- 이는 확정된 예측이 아닌 공개 정보 기반 참고용 스크리닝이다. "추천", "매수", "매도" 같은 단정적 표현을 쓰지 않는다.
- 출처 불명 정보만 있는 종목은 후보에서 제외한다.
